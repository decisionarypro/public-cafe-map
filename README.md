# 뜻밖의 카페 — Public Cafe Map

공공청사·공공문화시설에 있는 카페 가운데 특별한 방문 경험이 있는 장소를 발굴하는 **실험용 모바일 웹 MVP**입니다.

> **시범 서비스 / 상업적 검증 이전 버전**  
> 공개된 공식·언론 자료를 기반으로 후보 13곳을 정리했습니다(2026-10-31 조사). 현장 확인, 운영사 전화, 실제 방문자 테스트는 아직 진행하지 않았습니다. 영업·출입 정보는 변경될 수 있으므로 방문 전 운영기관에 확인하세요.

## 제품 요구사항(PRD)

- [통합 제품 요구사항 정의서 v1.0](PRD.md) — B2C/B2B 사업전략, 페르소나, 화면/기능, 데이터모델, 운영정책, 검증 지표, 개발 로드맵을 포함합니다.
- PRD는 전체 제품의 **목표 설계 문서**이며, 현재 저장소의 구현 완료 범위와 구분해서 확인해야 합니다.

## 바로 실행

- GitHub Pages를 활성화했다면 저장소의 Pages 주소에서 열 수 있습니다.
- 또는 `index.html`을 웹 브라우저에서 엽니다. 브라우저 보안정책에 따라 로컬 실행 시 일부 기능이 제한될 수 있으므로 GitHub Pages 방식을 권장합니다.
- 별도의 빌드, 패키지 설치, API 키, 백엔드가 필요하지 않습니다.

## 제공 기능

- 지역/목적별 장소 탐색과 간단한 검색
- **현행 관공서 청사** / **공공문화시설 확장 후보**의 구분
- 장소별 공식 출처, 주요 방문 가치, 미확인 정보 안내
- 장소 저장(브라우저 로컬 저장) 및 네이버지도 검색 연결
- 파일 내 로컬 이벤트 기록(중앙 서버로 전송되지 않음)

## 파일

| 파일 | 설명 |

| `.nojekyll` | GitHub Pages 정적 배포 시 Jekyll 처리 생략 |

## GitHub Pages 배포

저장소에는 `.github/workflows/deploy-pages.yml` 자동 배포 작업이 설정되어 있습니다.
`main` 브랜치에 파일이 갱신되면 GitHub Actions가 정적 사이트를 배포하도록 구성했습니다.

1. GitHub 저장소에서 **Actions** 탭의 `Deploy Public Cafe MVP to GitHub Pages` 실행 결과를 확인합니다.
2. 배포가 활성화되지 않으면 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. **Actions** 탭에서 워크플로를 다시 실행하거나 `main`에 변경사항을 커밋합니다.
4. 배포 성공 후 주소 `https://decisionarypro.github.io/public-cafe-map/` 에서 모바일 화면을 확인합니다.

**주의:** GitHub 저장소 업로드와 웹사이트 공개 배포는 별도 단계입니다. 배포 상태가 확인되기 전까지 위 URL의 작동을 보장하지 않습니다.

## 데이터 품질 및 서비스 운영 주의

- 목적 방문형/생활권형/A·B·C 분류는 **사업 검증용 내부 가설**이지 실제 소비자 평점·식약처 위생등급이 아닙니다.
- 전망대 운영시간과 카페 판매시간은 다를 수 있습니다. 기간 한정 이벤트를 상시 혜택으로 소개하지 마세요.
- 일부 공공문화시설은 관공서 *청사 내부 카페가 아니므로* 별도 표시합니다.
- 원본 데이터와 사진·상표의 이용 조건을 확인하고, 허가 없이 저작권 보호 사진을 재게시하지 마세요. 기본 UI는 외부 사진을 직접 삽입하지 않습니다.
- 시제품의 로컬 이용 로그는 전체 사용자의 통계를 수집하는 분석 시스템이 아닙니다.
- 이 사이트는 정부/지자체 공식 사이트가 아니며, 기관과의 제휴 또는 후원을 의미하지 않습니다.

## 향후 검증 계획

1. 실제 방문 시 최신 운영정보·출입 가능성을 확인하고 장소별 검증 일자를 갱신합니다.
2. 기존 지도 대비 방문 결정 및 검색 효율을 실사용자에게 비교 테스트합니다.
3. 발견 → 길찾기 → 실제 방문 → 자발적 재탐색 퍼널을 구분해 측정합니다.
4. 정량적 방문 성과가 발생하기 전에는 유료 광고·제휴의 매출 가능성을 확정하지 않습니다.

**현재 상태:** 시장 검증 전 연구 시제품. 데이터를 투자 분석이나 방문 보증에 사용하지 마세요.
